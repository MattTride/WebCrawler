# Changelog

All notable changes to Crawl Studio are documented in this file.

## [2.0.0] - Unreleased

### Added

- Integrated desktop workspace with persistent navigation and media inspector.
- Page intelligence for metadata, contacts, forms, resources, link classes, reading time, and SEO checks.
- Local crawl history with rerun, copy, delete, and clear actions.
- Live filtering for link, image, and video results.
- Multi-select media downloads with filename conflict handling.
- JSON, Markdown, HTML, and CSV report exports.
- Native desktop menus, application shortcuts, and version metadata.
- Automated tests on pushes and pull requests.

### Changed

- Rebuilt the interface around a compact command bar, metric strip, content workspace, and dark navigation rail.
- Improved error messages, task status visibility, and report content.
- Expanded release packages with SHA-256 checksum files.

## [1.0.0] - 2026-05-30

### Added

- Initial Python and tkinter desktop crawler.
- Single-page text, link, image, video, and HTML extraction.
- Media previews and individual downloads.
- macOS and Windows release packages.
